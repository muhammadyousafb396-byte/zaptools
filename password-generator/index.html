What makes a password strong?

Length matters most. A 16-character password mixing cases, digits and symbols has far more combinations than any attacker can brute-force. Our strength meter shows estimated entropy in bits — aim for 70+.

Security notes

  • Passwords are generated with your device's cryptographic random number generator.
  • Nothing is ever sent to a server or stored.
  • Use a unique password for every site, ideally saved in a password manager.

Frequently Asked Questions

Are generated passwords truly random?

Yes — we use crypto.getRandomValues, the browser's cryptographically secure random generator.

Should I use the generated password as-is?

Yes, and store it in a password manager rather than reusing passwords.

Is my password sent anywhere?

No. Generation happens 100% locally in your browser.
