Supported conversions

Text formats: TXT, CSV, JSON, Markdown and HTML convert between each other with smart parsing — CSV becomes a JSON table, JSON pretty-prints to readable text, Markdown renders to styled HTML.

DOCX files

Word documents convert to clean plain text or HTML. Complex formatting (embedded charts, SmartArt) may simplify — that's normal for any converter.

XLSX / PPTX note

Full spreadsheet and presentation conversion to PDF needs desktop software. Tip: copy a table from Excel and paste it here — choose CSV target to export it.

Frequently Asked Questions

Which conversions are supported?

TXT, CSV, JSON, Markdown and HTML convert between each other fully; DOCX converts to plain text or HTML; and you can bundle any files into a ZIP.

Can I convert XLSX or PPTX?

Paste table data to export it as CSV or JSON. Full XLSX/PPTX to PDF conversion needs desktop software like LibreOffice.

Is my file uploaded anywhere?

No — every conversion runs locally in your browser. Files never leave your device.

Is there a file size limit?

Browser memory is the only limit; files up to ~50 MB work smoothly.
