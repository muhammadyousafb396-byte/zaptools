Color formats explained

  • HEX (#4f46e5) — the web standard, used in CSS
  • RGB (79, 70, 229) — red/green/blue light values, 0–255
  • HSL (244°, 82%, 59%) — hue/saturation/lightness, intuitive for adjusting shades

Type in any field — the other two update automatically.

Frequently Asked Questions

What is the difference between HEX and RGB?

They describe the same color differently: HEX is a compact base-16 code, RGB lists the three light channels separately.

Can I pick from an image?

Use the native color picker — on most browsers it includes an eyedropper to sample any pixel on screen.
