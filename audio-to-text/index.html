How it works

Your browser's built-in speech recognition listens to your microphone and converts speech to text in real time. Works best in a quiet room — speak clearly and pause between sentences.

Browser support

Voice transcription needs the Web Speech API, available in Chrome and Edge (desktop & Android). Safari and Firefox don't support it yet — you'll see a clear message if your browser can't run it.

Frequently Asked Questions

Which browsers support voice transcription?

Chrome and Edge on desktop and Android. Safari and Firefox don't support the Web Speech API yet.

Is my voice recording uploaded?

Speech is processed by your browser's built-in recognition service; the transcript text stays on this page.

Can I transcribe an audio file?

This tool transcribes live microphone input. Play your audio file near the mic, or use desktop software for file transcription.

Which languages are supported?

Pick from 10+ languages including English, Urdu, Hindi, Arabic and Spanish in the language dropdown.
