Counting days between dates

Useful for project timelines, pregnancy weeks, visa stays and event countdowns. Toggle inclusive counting when both the start and end day should count (common for bookings).

Frequently Asked Questions

Does it handle leap years?

Yes — calculations use real calendar dates, so Feb 29 is counted correctly.

What does inclusive mean?

Inclusive counts both endpoints: Jan 1 to Jan 1 inclusive = 1 day; exclusive = 0 days.

Can the end date be before the start?

Yes — you'll get a negative day count showing the gap backwards.
