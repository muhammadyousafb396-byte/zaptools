Sort Lines Alphabetically

Sort any list A–Z, Z–A, by length — or shuffle it randomly.

Home › Alphabetical Line Sorter

Sorting options

  • A → Z: standard alphabetical (locale-aware)
  • Z → A: reverse alphabetical
  • By length: shortest lines first
  • Shuffle: cryptographically random order

Frequently Asked Questions

Does sorting ignore case?

Sorting is locale-aware: 'apple' comes before 'Banana' as you'd expect.

Can I sort numbers?

Yes — but as text. For numeric sorting use the length option or pad numbers.

Is shuffle truly random?

Yes, using cryptographic randomness.
