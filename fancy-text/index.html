What is fancy text?

These are Unicode mathematical symbols that look like styled letters. Because they're plain text characters, they work in Instagram bios, TikTok names, WhatsApp and anywhere text is accepted — no font installation needed.

Frequently Asked Questions

Will fancy text work on Instagram?

Yes — Instagram, TikTok, Twitter and Facebook all render Unicode symbols.

Why do some characters show as boxes?

Very old devices lack newer Unicode glyphs; most modern phones display them fine.

Is it accessible?

Screen readers may read symbols oddly, so use fancy text sparingly in important content.
