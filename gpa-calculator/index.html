4.0 GPA scale

Each grade maps to grade points (A = 4.0 … F = 0). GPA = total grade points ÷ total credit hours. Weighted honors/AP scales vary by school — this uses the standard unweighted 4.0 scale.

Frequently Asked Questions

What's the difference between semester and cumulative GPA?

Semester covers one term; cumulative averages all terms weighted by credits.

Does A+ count more than A?

On the standard 4.0 scale both are 4.0; some schools weight A+ as 4.3.

Can I save my courses?

This version calculates on the fly; bookmark the page and re-enter each term.
