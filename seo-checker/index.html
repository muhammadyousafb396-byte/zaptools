    What we check

    On-page SEO fundamentals: title tag presence and length, meta description, single H1, heading structure, image alt attributes, Open Graph tags, canonical URL, mobile viewport, link count and content depth. Each factor is weighted into a 0–100 score.

    Limitations

    We analyze the static HTML — JavaScript-rendered content, page speed, backlinks and Core Web Vitals need dedicated tools like PageSpeed Insights and Search Console. Note: to read another site's HTML, your browser fetches it through a third-party proxy (corsproxy.io), so the audited page's HTML passes through that service. A failed fetch is reported as an error, never as a score of 0.

    Frequently Asked Questions

    Why did the fetch fail?

    Some sites block proxy fetching or need JavaScript rendering. Try the site's homepage or a simpler page.

    Is a 100 score a ranking guarantee?

    No — on-page basics are necessary but not sufficient; content quality and backlinks matter more.

    Is my audited URL stored?

    No. The URL is fetched live and nothing is saved.
