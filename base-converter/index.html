Number bases explained

  • Binary (2): how computers store everything — 0s and 1s
  • Octal (8): legacy Unix permissions
  • Decimal (10): everyday counting
  • Hexadecimal (16): colors (#FF0000), memory addresses

Frequently Asked Questions

Why do programmers use hex?

One hex digit = 4 bits, so bytes map neatly to 2 hex digits — compact and readable.

What is 255 in binary?

11111111 — eight ones, the max value of one byte.

Can it handle negative numbers?

This tool converts non-negative integers; negatives use two's complement in real systems.
